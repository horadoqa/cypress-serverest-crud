# cypress-serverest-crud

Projeto de automação de testes utilizando **Cypress** e a API **ServeRest**, com foco na validação das operações CRUD (_Create, Read, Update e Delete_) de usuários em um ambiente de e-commerce.

## Objetivo

Praticar e demonstrar conhecimentos em automação de testes, validação de APIs e qualidade de software, utilizando o Cypress para testar o ciclo de vida de usuários.

## Funcionalidades testadas

- **Create:** cadastro de usuários.
- **Read:** consulta de usuários cadastrados.
- **Update:** atualização dos dados de usuários.
- **Delete:** exclusão de usuários.

## Tecnologias utilizadas

- [Cypress](<https://www.cypress.io/>)
- [ServeRest](<https://serverest.dev/>)
- [JavaScript](https://www.w3schools.com/js/)
- [Node.js](https://nodejs.org/pt-br)
- Git e GitHub

## Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/horadoqa/cypress-serverest-crud.git
```

2. Acesse a pasta do projeto:

```bash
cd cypress-serverest-crud
```

3. Instale as dependências:

```bash
npm install
```

4. Execute os testes:

```bash
npx cypress open
```

Ou execute em modo headless:

```bash
npx cypress run
```
