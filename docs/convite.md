Novo projeto de QA Automation no GitHub!

Estou desenvolvendo o Cypress ServeRest CRUD, um projeto de automação de testes utilizando Cypress e JavaScript, com foco nas operações de gerenciamento de usuários (CRUD) na API ServeRest.

O objetivo é validar as principais operações de criação, consulta, atualização e exclusão de usuários, aplicando boas práticas de automação de testes e validação de respostas HTTP.

O que você encontrará no projeto?

- Testes de API com Cypress.
- Operações de Create, Read, Update e Delete (CRUD).
- Validação de status HTTP e respostas da API.
- Verificação da consistência dos dados dos usuários.
- Prática de automação de testes e qualidade de software.

O projeto é um template para sua jornada de aprendizado e evolução contínua em Qualidade de Software e automação de testes.

Este é apenas o começo! 

O projeto ainda possui pontos de melhoria e oportunidades de evolução para se tornar cada vez mais robusto e escalável.
