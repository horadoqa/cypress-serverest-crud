**Data:** 21/10/2026 - 
**Tipo:** Criação de funcionalidade
**Projeto:** Cypress ServeRest CRUD

## Descrição

Implementação de testes automatizados de API utilizando **Cypress e JavaScript** na aplicação ServeRest, com foco nas operações CRUD de usuários.

## Funcionalidades implementadas

- **Create:** cadastro de usuários.
- **Read:** consulta de usuários cadastrados.
- **Login:** autenticação de usuários.
- **Update:** atualização dos dados de usuários.
- **Delete:** exclusão de usuários, utilizando o ID retornado no cadastro.
- **Testes de contrato:** validação da estrutura das respostas e dos tipos de dados dos endpoints de usuários.

## Validações realizadas

- Verificação dos status HTTP.
- Validação dos dados retornados pela API.
- Verificação da consistência das respostas.
- Validação dos contratos dos endpoints de listagem e consulta por ID.

## Resultado

Implementação concluída e testes executados com sucesso, contribuindo para a qualidade, a confiabilidade e a manutenção da API por meio da automação de testes.
